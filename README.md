**SDK22** は、端末に保存されたGalax-ShhのAPKファイルを、Androidの**ワイヤレスデバッグ**機能を利用してインストールするアプリです。

Android14以降でインストールがブロックされてしまう古いアプリ（TargetSDKVersion 22以下）を、バイパスしてインストールすることができます。

※アプリアイコンはアプリの機能と一切関係ありません。

---

## 🌟 主な特徴

- 🚀 **古いアプリ（TargetSDK 22以下）のインストール対応**  
  Android 14以降で通常インストーラーから拒否されるアプリも、ワイヤレスデバッグ経由でインストールできます。
- 🛡️ **事前セキュリティ診断**  
  すべてのAPKファイルについて、インストール前にデジタル署名や危険な権限の組み合わせ（SMS転送や不正操作のリスク等）を端末内で自動診断。確認と同意のうえでインストールできます。
- 🔔 **かんたんWi-Fiペアリング**  
  開発者オプションのペア設定画面を開くだけで自動的にポートを検出。通知エリアから「画面に表示された6桁のコード」を入力し送信して簡単にペアリングが完了します。
- 🔑 **2回目以降の自動接続**  
  初回ペアリング後は鍵情報が安全に保持されるため、再ペアリング不要でスムーズに接続できます。

## 🚀 使い方

### 1. 初回セットアップ（ペアリング）
1. 端末をWi-Fiに接続します。
2. 開発者向けオプションを有効化していない場合は、端末設定の端末情報→ソフトウェア情報→ビルド番号を7回タップしてパターン入力して開発者向けオプションを有効化してください。
3. アプリ初回起動時に出るアプリの通知を許可する。
4. アプリ画面の「**開発者オプションを開く**」をタップし、開発者向けオプションの中の「**ワイヤレスデバッグ**」をONにします。
   - ※「ワイヤレスデバッグ」がグレーアウトしてONにできない場合（Galaxy端末等）は、端末設定のセキュリティ設定の「**自動ブロッカー**」を一時的にOFFにしてください。
5. 「**専用コードによるデバイスのペア設定**」をタップしてWi－Fiペア設定コードを表示させます。（※このポップアップが表示された状態でペアリングする必要があります。）
6. 通知に「**ペア設定コードの入力**」の案内が表示されます。
7. 本アプリの通知ポップアップかステータスバー通知の［**コード入力**］か右端のボタン﹀をタップし、画面に表示されている**6桁のコード**を入力して送信してペアリング完了通知が出ればペアリング完了です。

### 2. APKのインストール
1. アプリ内「**ファイルを選択**」をタップし、インストールしたい APK ファイルを選択します。
2. 表示されるセキュリティ診断結果を確認します。
3. 同意チェック(危険が無いと判断した場合は表示されません)を入れて「**ADBでインストール**」をタップします。
4. Google Play プロテクトの警告ポップアップが出るので詳細をタップし内容を確認し内容に納得したらインストールするをタップして認証する。（OKをタップすると[ブロックしました]の内容の了承となりインストールされません）
5. インストール完了後は、本アプリは不要のためアンインストールして大丈夫です。残す場合は、ワイヤレスデバッグをOFFにしてください。

## 🔒 アプリが使用する権限

| 権限 | 用途 |
|---|---|
| `POST_NOTIFICATIONS` | 6桁のペア設定コードを通知から直接入力するために使用 |
| `INTERNET` | 端末内（ローカル）でのワイヤレスデバッグ接続に使用 |
| `ACCESS_NETWORK_STATE` | Wi-Fi接続状態の確認に使用 |
